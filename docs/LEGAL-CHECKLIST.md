# 一般公開のための法務まわり：入力・判断が必要な項目

対象: 特定商取引法に基づく表記（`/commerce`）、利用規約（`/terms`）、プライバシーポリシー（`/privacy`）、お問い合わせ（`/contact`）、購入前の確認事項（`/art-slide/premium`）。

> **これは法的助言ではありません。** 日本の消費者庁の公開資料（下記）に沿って作った初版です。公開前に、ご自身で内容を読み、不安があれば、弁護士・行政書士・商工会議所の相談窓口などに確認してください。
> 運営者情報は、**ご自身で入力した値だけ**が表示されます。未入力の項目は、黄色の【未設定】で表示され、**5 項目（下記A）がそろうまで購入ボタンは使えません**。

私は、これらを**一切入力・推測していません**。値を教えていただければ、コードに入れます（または、ご自身で `operator.ts` を編集してください）。

|---|---|---|---|---|
| A1 | 販売事業者名（`name`） | ✅ | 個人事業の場合は**氏名**（本名） | 屋号だけでは足りません。個人でも、氏名を表示するのが原則です（下記 B の例外を除く） |

| A4 | 電話番号（`phone`） | ✅ | 同上 | 同上 |
| A5 | メールアドレス（`email`） | ✅ | 問い合わせ用のメールアドレス | 公開されます。**請求時開示の請求を受ける窓口**にもなります。個人情報の開示請求の窓口も、このアドレスです |

## B. 住所・電話番号を省略（請求時開示）できる条件

**消費者庁の「特定商取引法ガイド」の記載（通信販売）:**
- 事業者の住所・電話番号などは、広告に「**請求があれば、遅滞なく提供する**」旨を表示し、**実際に請求があったとき遅滞なく提供できる措置**を講じていれば、表示を省略できます（法11条ただし書）。
- 「遅滞なく」とは、**申込みの意思決定の前に十分な時間的余裕をもって**提供されることです（実務上は、1 週間程度を目安とする解説もあります）。
- **個人事業者**の場合: 住所は**現に活動している場所**、電話番号は**確実に連絡が取れる番号**でなければなりません（請求されたときに、それを提供します）。
- **私書箱は「住所」として認められません**。バーチャルオフィスは、条件つきで認められますが、連絡が取れなくなれば表示義務を果たしたことになりません。
- **省略できない項目:** 返品に関する事項、動作環境、継続契約の条件、特別な販売条件など。これらは、必ず表示します（本サイトは表示済み）。

**実装との対応:** A3・A4 を `{ mode: 'on-request' }` にすると、サイトは「請求があった場合には、遅滞なく開示いたします（〈メール〉までご請求ください）。」と表示します。

**あなたが決めること（判断）:**
1. 住所・電話番号を**公開する**か、**請求時開示**にするか。
2. 請求時開示にする場合: ①請求を受けたら、**実際に、遅滞なく（購入の判断に間に合うように）メールで返信する**体制を取れるか。②開示する**住所は、実際に活動している場所**（自宅など）、**電話は、確実に連絡が取れる番号**か。（これらが用意できないなら、公開にするか、バーチャルオフィス・転送電話サービスなどの利用を検討）
3. 氏名（A1・A2）は、**公開**を推奨します（Stripe は運営統括責任者を省略不可としており、氏名の請求時開示が認められる範囲は解釈が分かれるため）。氏名の非公開を希望する場合は、専門家に確認してください。

**参考:** Stripe アカウント自体には、事業者の住所・電話番号などの登録が必要です（領収書やカード明細に出る情報を含む）。公開する情報とは別に、Stripe の画面で設定します。

## C. 判断が必要な項目（内容は初版を入れてあります。実態と合うか確認してください）

| # | 項目 | 現在の文面 | 判断 |
|---|---|---|---|
| C1 | **返金** | 申込み後の返金・期間途中の日割り返金は行わない（法令で認められる場合を除く）。当方の責めに帰すべき事由でサービスを提供できなかった場合は個別に対応 | この方針でよいか。通信販売には**クーリング・オフはありません**が、「返品不可」は**明確に表示する必要**があります（表示済み） |
| C2 | **料金改定** | 適用日の **30 日前**までに告知。次回更新から適用。同意しない場合は解約できる | 30 日でよいか |
| C3 | **解約の期限** | 「**次回の更新日時より前**」に手続きすれば次回は請求されない | 更新日の前日までなど、より厳しい期限にする場合は、システム側の確認が必要（今はお申し込みと同じ日時に更新される） |
| C4 | **支払総額の表示** | 契約期間の定めがないため確定しない。目安：6 か月 1,200 円・12 か月 2,400 円 | 定期購入では、総額・継続の条件を最終確認画面にも表示することが求められます（購入画面に表示済み） |
| C5 | **責任の制限** | 故意・重過失を除き、通常の損害に限り、Premium は「損害が生じた月に支払った料金」を上限。消費者契約法で認められない場合は適用しない | この上限でよいか |
| C6 | **未成年** | 親権者等の同意を得て申し込む | 年齢制限を設ける場合は追記 |
| C7 | **サービス変更時の対応** | Premium 期間中に主要な機能が提供できなくなった場合は、期間・料金について利用者の利益に配慮して対応 | 具体的な約束（日割り返金など）にするか |
| C8 | **マイフォト** | 利用者が権利を持つ画像のみ。端末内だけに保存し、送信・共有・Drive 保存なし。ブラウザのデータ消去で消える | 実装と一致しています（変更時は文面も変更） |
| C9 | **プライバシー：保存期間** | セッション最長 30 日／アカウントは削除まで／ログイン回数制限は IP のハッシュを最長 10 分 | 実装と一致（今回、IP をそのまま保存していた点を、ハッシュ化＋自動削除に**修正済み**） |
| C10 | **広告** | 忍者AdMax。EU 等は同意後に配信。Premium は広告なし | 広告事業者の最新の案内（個人情報の取扱い）に合わせて確認 |
| C11 | **お問い合わせの対応** | A5・A9 の内容 | 回答の約束をするなら、守れる範囲で |

| # | 事項 | 内容 |
|---|---|---|
| D1 | 課税事業者か免税事業者か・インボイス登録 | A6・A10 に影響します。税務署・税理士に確認 |
| D2 | 個人情報保護法 | 個人事業でも、個人情報取扱事業者として、利用目的の公表・安全管理・開示請求への対応が必要です（プライバシーポリシーに記載済み）。外国の事業者（Cloudflare・Google・Stripe）の利用についても記載済み |

| D4 | Google の OAuth 同意画面 | 運営者のメール、プライバシーポリシー・利用規約の URL の登録が必要。`workers.dev` が承認済みドメインとして使えるかの確認（だめなら独自ドメイン） |
