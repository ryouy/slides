## 2. 確認結果

### 2-1. 氏名・住所・電話番号を請求時開示にできるか（消費者庁「通信販売広告Q&A」Q15・Q16・Q17）

| 確認した内容 | 結果 |
|---|---|
| 個人事業者の**氏名**・住所・電話番号を省略できるか | **できます。** 広告に、請求があれば書面または電子メール等で**遅滞なく提供する旨を表示**し、実際に請求があったとき**遅滞なく提供できる措置**を講じていれば足ります（Q15・Q17） |
| 「遅滞なく」とは | 申込みの意思決定に先立って、十分な時間的余裕をもって提供されること（Q17）。日数の定めはありません |
| 開示するときの氏名 | **戸籍上の氏名**。通称・屋号・サイト名だけは認められません（Q16） |
| 開示する住所・電話 | 住所は**現に活動している場所**、電話は**確実に連絡が取れる番号**。私書箱は不可（Q17・Q19） |
| 省略できない項目 | 返品に関する事項、動作環境、継続契約の条件、特別な販売条件など（表示済み） |
| 表示の場所 | 広告から容易に到達できる場所に表示。「同じサイト内で表示できるのに、外部サイトへのリンク先に記載するのは通常認められない」（特商法表記は**サイト内**にあります。フォームは請求の受付窓口で、開示そのものはサイト内の表記が根拠です） |

### 2-2. 個人事業者の「運営統括責任者」の表示要件

- 消費者庁の資料に、「**運営統括責任者**」という用語はありません。定められているのは、**法人**がインターネットで広告する場合に、**代表者または通信販売業務の責任者の氏名**を表示することです（Q15。責任者は代表権がなくてよい）。
- **個人事業者**は、販売事業者本人が責任者です（別の責任者の氏名は求められません）。氏名の省略（請求時開示）は、上のとおり認められます。
- サイトでは、「個人事業のため、販売事業者（上記）本人です」と表示します。法人にする場合は、`representative` に責任者名を入れます（空のあいだは購入ロック）。

### 2-3. Google フォームでの受付は問題ないか

**法令上:** 請求の**受付手段の指定はありません**（消費者庁の資料に、メール・フォーム等の定めは見当たりませんでした）。フォームでも、次の運用ができれば、「請求があれば遅滞なく提供できる措置」に当たると考えられます。**ただし、現在のフォームは、このままでは不十分です**（実際に開いて確認しました）。

| 項目 | 現在のフォーム | 必要な対応（**あなたの作業**） |
|---|---|---|
| ログインなしで送信できるか | ✅ できる | — |
| 「事業者情報の開示請求」の選択肢 | ❌ **ない**（不具合／Premiumお支払い／アカウントデータ／その他） | 「お問い合わせの種類」に「**事業者情報の開示請求**」を追加（サイトの案内文と同じ名前に） |
| 返信先メールアドレス | ❌ **任意** | 開示請求を選んだ場合は**必須**にする（Googleフォームの「セクションに基づいて移動」で、種類が開示請求のとき、必須のメール欄があるセクションへ進める）。返信先がなければ、開示のしようがありません |
| 新しい回答の通知 | 未確認 | 「回答」→「⋮」→「新しい回答についてのメール通知を受け取る」をオン（見落とすと「遅滞なく」を守れません） |
| 利用目的の表示（個人情報保護法） | ❌ 説明文なし | フォームの説明に、「入力内容は、返信と開示請求への対応のためだけに使います」とプライバシーポリシーへのリンクを追加 |
| 対応の体制 | — | 請求を受けたら、**購入の判断に間に合うよう**（目安：3 営業日以内）、戸籍上の氏名・実際の住所・つながる電話番号を、メールで返信する。返信の記録を残す |

**「適法な請求があった場合」について:** サイトは、法律の文言どおり「**請求があった場合には**、遅滞なく開示します」と書いています。方針の「適法な請求」に限定する書き方は、**入れていません**（請求者を絞る書き方は、表示義務を満たさないおそれがあります）。本人確認が必要な場合は、返信先の確認の範囲にとどめてください。

### 2-4. Stripe の審査

Stripe の「特定商取引法に基づく表記ページの作成と表示方法」で確認できた内容:

| 項目 | Stripe の案内 |
|---|---|
| 「請求があれば遅滞なく開示」と書ける項目 | **法人名（個人事業主の場合）・所在地・電話番号**の 3 つ |
| メールアドレス | 必須項目。顧客の問い合わせに対応できるメールアドレス。**フォームの URL で代替できるかの記載はありません** |
| 運営統括責任者 | 必須項目。**個人事業主の場合の扱い・氏名を非公開にできるかの記載はありません**。請求時開示にできる項目の中にも入っていません |
| 審査での確認方法 | 記載なし（法令の遵守を保証するものではない、との注意書きのみ） |

**結論（未解決）:** あなたの方針（氏名・メールを公開しない）は、**消費者庁の資料に照らせば認められる**（氏名・住所・電話の省略）一方、**Stripe の案内とは一致しません**（Stripe は、メールアドレスと運営統括責任者を、請求時開示の対象にしていません）。**Stripe の本番申請の審査で、修正を求められる可能性があります。**テストモードでは審査されないため、本番申請まで分かりません。私が「問題ない」と判断することはできません。

対応案（**あなたの判断**）:
1. **このまま本番申請する。** 修正を求められたら、下の 2 か 3 に切り替える（サイトの設定変更だけで済みます）
2. **専用の公開用メールアドレスを作る**（個人のメールではなく、サービス専用に新規に取得したもの）。`email` に入れると、特商法表記に表示されます（フォームと併記）。個人のメールは公開されません
3. 氏名を公開する（`name` を `{ mode: 'public', value: '戸籍上の氏名' }`）
